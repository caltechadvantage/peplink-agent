# Peplink

Kiosk agent for MobileLinQ kits built on a Peplink router. It runs on the kit's Raspberry Pi touchscreen, shows the router's WAN, cellular radios, Wi-Fi and battery, and publishes telemetry to ThingsBoard for the DTS dashboard. When a Starlink dish is plugged into the router it also shows the dish screens.

Started from the Starlink agent 1.12.1. See `docs/INSTALL.md` to install and update a kit, and `CHANGELOG.md` for releases.
